# networks_hws

## Установка и запуск

```
git clone https://github.com/d3clane/networks_hws.git
g++ -O2 socket_chat.cpp -o socket_chat
./socket_chat tcp server IP PORT
```

Как использовать описано в usage внутри socket_chat.cpp (принтится при неправильном использовании)

## TCP 

Реализуется в функциях где приписано в названии tcp. Считаю что сообщения делятся на '\n' всегда, поэтому никакой длины не отправляю вместе с сообщением -- читаю до новой строки. Когда начинает приходить новое сообщение на сервер, он блокируется, пока не считает полностью новое сообщение (то есть с консоли не читает ниче в этот момент). Один клиент за раз. 

Так как сообщения типо разделяются \n, то любой размер поддерживается, 20КБ тоже. Что сервер, что клиент делают read_until_enter, читают любое число пакетов подряд до энтера. При этом, так как это tcp, то все в правильном порядке и точно доходит. Если нет гарантии, что есть разделитель \n, то можно переписать на то, что вначале отправляется число соответствующее количеству байтов следующих дальше.
